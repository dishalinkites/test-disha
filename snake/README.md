# Snake Game

A lightweight HTML5 Canvas Snake game.

## Run locally

- Use any static server from the repo root or snake/ directory, e.g.:
  - python3 -m http.server 8000 -d snake
  - npx serve snake
- Open http://localhost:8000

## Controls
- Arrow keys / WASD to move
- Space: pause/resume
- R: restart
- Tap on-screen D-pad on mobile

## Deploy
The deploy workflow file deploy.yml (in repo root) publishes snake/ to gh-pages. Production URL:
https://dishalinkites.github.io/test-disha/
